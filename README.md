# Thanh Tai Pham Tran — Academic Portfolio

A lightweight static portfolio for academic and research outreach.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for the deployment and visit https://thanh-tai-435.github.io/.

## Before sharing with professors
- Replace the email and LinkedIn placeholders in `index.html`.
- Upload your latest approved CV to `assets/cv.pdf`.
- Verify GPA, dates, job titles, project status, and your exact contribution.
- Add evidence (GitHub repositories, papers/preprints, diagrams, demos) to each project page.
- Do not publish confidential company information, client data, credentials, or proprietary formulas.

This is an initial public-facing draft. Update all unverified statements before using it for formal applications.
